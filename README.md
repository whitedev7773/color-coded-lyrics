# Color Lyrics

아티스트별 컬러 코드 가사 플레이어. 가사를 넘기면 해당 파트를 부르는 아티스트 사진이 컬러로 강조되고, 나머지는 흑백으로 처리됩니다.

## 미리보기

- 아티스트 사진 영역 (상단 52%) — 포커스된 아티스트는 컬러 테두리 + 컬러 글로우
- 가사 영역 (하단) — 일본어 원문 / 로마나이즈 / 한국어 번역 3줄 표시
- 복수 아티스트 동시 포커스 시 색상 그라데이션 적용

## 가사 형식

```
[파트명] #아티스트명 가사 첫 줄
로마나이즈
한국어 번역

[다음 파트] #아티스트1+아티스트2 가사 첫 줄
로마나이즈
한국어 번역
```

| 태그 | 설명 |
|------|------|
| `[파트명]` | 섹션 이름 (1절, 후렴 등). 등장 시 4초간 애니메이션과 함께 표시 |
| `#아티스트명` | 해당 줄부터 포커스될 아티스트 |
| `#아티스트1+아티스트2` | 복수 아티스트 동시 포커스 |
| `# .` | 포커스 없음 (전원 흑백) |
| `#` 태그 없음 | 직전 그룹의 아티스트 상태 유지 |
| `.` 만 있는 줄 | 공백 처리 |

그룹은 **빈 줄**로 구분합니다.

## 단축키

| 키 | 동작 |
|----|------|
| `←` / `→` | 이전 / 다음 가사 |
| `E` | 가사 입력 창 열기 |
| `B` | 배경 이미지 선택 |

## 커스터마이징

- **아티스트 사진** — 사진 영역 클릭
- **아티스트 색상** — 이름 텍스트 클릭 → 컬러피커
- **배경 이미지** — `B` 키 → 이미지 선택 (블러 + 흰 오버레이 적용)
