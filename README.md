# Color Lyrics

아티스트별 색상과 이미지를 입혀서 가사를 보여주는 데스크톱형 웹 플레이어입니다.  
현재 버전은 리퀴드 글래스 스타일 UI를 적용했고, 배경 이미지와 음악 파일을 함께 불러와서 가사 진행에 맞춰 감상할 수 있습니다.

## 주요 기능

- 아티스트별 패널 표시
- 현재 파트를 부르는 아티스트 강조
- 일본어 / 로마자 / 한국어 3줄 가사 표시
- 여러 아티스트 동시 등장 시 그라디언트 텍스트 적용
- 배경 이미지 업로드
- 음악 파일 추가 및 재생/일시정지 단축키 지원
- 리퀴드 글래스 느낌의 반투명 UI

## 화면 구성

- 상단: 아티스트 이미지와 이름 패널
- 중앙: 파트 라벨
- 하단: 3줄 가사 영역
- 배경: 업로드한 이미지에 블러와 오버레이 효과 적용

## 가사 입력 형식

아래 형식으로 가사를 붙여넣으면 됩니다.

```text
[Verse 1] #Eve
廻廻奇譚
kaikai kitan
회회기담

[Chorus] #Eve+Suis
...
...
...
```

규칙은 다음과 같습니다.

- `[파트명]` : 현재 섹션 이름
- `#아티스트명` : 해당 줄을 부르는 아티스트
- `#아티스트1+아티스트2` : 여러 아티스트가 함께 부르는 줄
- `#.` : 강조할 아티스트 없음
- `#` 태그가 없으면 직전 아티스트 상태를 유지
- 한 묶음은 빈 줄로 구분
- 각 가사 블록은 기본적으로 3줄을 사용

## 단축키

| 키 | 동작 |
|----|------|
| `←` | 이전 가사 |
| `→` | 다음 가사 |
| `E` | 가사 입력 창 열기 |
| `B` | 배경 이미지 추가 또는 변경 |
| `M` | 음악 파일 추가 또는 교체 |
| `Space` | 음악 재생 / 일시정지 |
| `K` | 음악 재생 / 일시정지 |

입력창(`textarea`)에 커서가 있을 때는 단축키가 가로채지지 않도록 처리되어 있습니다.

## 커스터마이징

- 아티스트 이미지: 상단 아티스트 패널 클릭
- 아티스트 색상: 아티스트 이름 클릭
- 배경 이미지: `B` 또는 배경 선택
- 음악 파일: `M`으로 오디오 파일 선택

## 개발 환경

```bash
npm install
npm run dev
npm run build
npm run preview
```

기본 개발 서버는 Vite 설정을 따릅니다.

## 기술 스택

- TypeScript
- Vite
- Modular CSS
- HTML Audio API

## 메모

- 앱 시작 시 가사 입력 다이얼로그가 먼저 열립니다.
- 음악 재생은 사용자가 파일을 직접 선택한 뒤에만 동작합니다.
- 배경 이미지와 음악은 모두 로컬 파일 기반으로 불러옵니다.
